# NOVA ROBOTICS — Website Starter

Responsive static website starter using HTML, CSS, and JavaScript. No framework or paid service is required.

## Files
- `index.html` — page content and structure
- `styles.css` — futuristic dark and electric-neon-blue styling
- `script.js` — mobile navigation, current year, email-draft contact form

## Before publishing
1. Open `script.js` in a text editor.
2. Replace `replace-with-your-email@example.com` with an email address you control.
3. Review all website text and remove anything you do not want to claim publicly.
4. NEXUS is a fictional concept illustration made with CSS shapes. It is not a built or tested robot.

## Preview on Windows
1. Extract this ZIP.
2. Open the `nova_robotics_website` folder.
3. Double-click `index.html` to preview in your browser.
4. Edit files using Visual Studio Code or another text editor.

## Free publishing with GitHub Pages
1. Sign in to GitHub or create an account.
2. Create a new **public** repository, for example `nova-robotics-site`.
3. Upload `index.html`, `styles.css`, `script.js`, and `README.md` into the repository root.
4. Open repository **Settings → Pages**.
5. Under build/deployment source, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then save.
7. Wait for deployment. GitHub Pages will show your site URL in the Pages settings. It usually resembles `https://YOUR-USERNAME.github.io/nova-robotics-site/`.

Official instructions: https://docs.github.com/pages

## Contact form note
This static form opens the visitor's email app with a prepared draft after you configure `CONTACT_EMAIL`. It does not send messages directly to a server and does not store submissions.
